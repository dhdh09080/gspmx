# Procedure
1. Inspect labels, keyboard interaction, autocomplete, focus, dialogs and mobile layout.
2. Review loading, empty, success, duplicate, rejection and network failure states.
3. Preserve three request types, history and pending-only edit/delete.
4. Separate manual findings from executed automated tests.
Do not redesign the entire app without approval.
